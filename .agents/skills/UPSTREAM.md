# App Store Connect skills

These project-local skills are copied without modification from
[`rorkai/app-store-connect-cli-skills`](https://github.com/rorkai/app-store-connect-cli-skills/tree/f52c4f04323bb2dfb21ca8be82e6494e9cd0b4d8/skills)
at reviewed commit `f52c4f04323bb2dfb21ca8be82e6494e9cd0b4d8`. The upstream
MIT license is included beside the skill directories.

The `asc` executable is a separate local tool; the skill files do not install
it or configure App Store Connect credentials. `asc auth login --local` stores
credentials in `.asc/config.json`, which this repository ignores at any depth.
